SOS Emergency Pipeline
Volume shortcut → Siren → SMS → Video → FCM push notification
sequenceDiagram
    participant U as 👤 User
    participant VOL as 🔊 VolumeShortcut
    participant APP as 📱 App.jsx
    participant SOS as 🚨 SOSScreen
    participant CAM as 📹 Camera
    participant LOC as 📍 Location API
    participant SMS as 💬 SMS / Linking
    participant SOCK as 🌐 Socket.IO
    participant SIREN as 🔔 SOSSirenService
    participant FS as 🗄️ Firestore
    participant CF as ⚡ Cloud Function
    participant FCM as 📲 FCM Push

    U->>VOL: Press Volume Down ×3
    VOL->>APP: onTriggered()
    APP->>SOS: navigate("SOS")
    activate SOS
    SOS->>SOS: playSiren() 🔊
    SOS->>CAM: recordAsync(60s) 📹
    SOS->>LOC: getCurrentPositionAsync()
    LOC-->>SOS: {lat, lon}
    SOS->>SMS: openURL(sms:contacts)
    SOS->>SOCK: emit("send_distress")
    SOS->>SIREN: triggerSOSSiren()
    SIREN->>FS: sos_alerts.add()
    SIREN->>FS: siren_triggers.add()
    FS-->>CF: onCreate trigger
    CF->>FCM: sendEachForMulticast()
    FCM-->>U: 🚨 Push Notification
    deactivate SOS
